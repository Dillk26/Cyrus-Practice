Unit 1 Quick Reference

1. Justifications (Standard #1)
  • Distribution: Multiply outside term across parentheses, e.g. $a(b+c) = ab + ac$.
  • CLT (Combine Like Terms): Add/subtract terms on the same side with the same variable.
  • POE (Property of Equality): Add, subtract, multiply, or divide both sides by the same value.
2. The Golden Inequality Rule

Whenever you multiply or divide both sides by a negative number, you MUST flip the inequality sign ($<$ becomes $>$, $\le$ becomes $\ge$).

3. Number Line Circles
Open: $<$ or $>$ Closed: $\le$ or $\ge$
4. Absolute Value Rules
  • Isolate $|expression|$ first!
  • If $|X| = \text{negative}$, there is No Solution.
  • Less thAND ($\le, <$): $-c < X < c$ (shaded between).
  • GreatOR ($\ge, >$): $X > c \text{ or } X < -c$ (shaded apart).
